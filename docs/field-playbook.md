# Soybean harvest playbook

Tomorrow’s walk is Hiroki Tomiyasu’s soybean field in Hokkaido, during harvest. The crop is soybean. The place is his field. Type the coordinates on site. This page does not contain them.

Record what you measured:

- GPS latitude and longitude
- the time, stored in UTC when you save
- a row or sample id
- a photo path, if you took a photo
- the harvest unit you are using
- moisture, only if a meter is in your hand

Leave a field blank when you did not measure it. GPS accuracy stays unknown unless you type metres you actually read. Do not type a yield, a futures price, or a coordinate you did not read.

The file is a field note. It is not a buy, a sell, a hedge, a trigger, or a yield forecast. Class C stays closed. Financial use stays false.

Later dates, with no country datasets, are in `docs/later-routes.md`.
